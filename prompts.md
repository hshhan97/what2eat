# Core Prompts

## Plan Assembly Prompt
You are assembling a weekly meal plan using ONLY the provided structured recipes.
Prioritize recipes with higher pantry overlap and minimize new ingredients.
Ensure protein targets are met.

## Swap Prompt
Replace the selected meal with another option from the candidate list 
that satisfies dietary restrictions and protein requirements.

## Repair Prompt
If constraints are violated, regenerate ONLY the failing meals.
